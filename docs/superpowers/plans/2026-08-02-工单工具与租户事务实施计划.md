# 工单工具与租户事务实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有工单领域模型和租户 Unit of Work 上增加确定性 `ticket.create` / `ticket.update` 工具，并通过工单应用服务在 Guard 通过后写入租户内工单、消息、事件、审计和运行时追踪。

**Architecture:** `TicketTool` 只通过 `SupportRepository` 操作当前租户工单；`TicketWorkflowService` 先运行主图 Guard 和路由，再在同一个 Unit of Work 内执行工单工具、审计和运行时记录。模型不能直接决定或执行工单写入。

**Tech Stack:** Python 3.11.15、LangGraph 1.0.9、SQLAlchemy 2.0.36、Pydantic 2.11.4、pytest 8.3.4。
