# Mock 外部服务实施计划

**Goal:** 建立独立可测试的 Billing、CRM、Monitoring 和 Notification 模拟外部服务，并提供异步 HTTP 客户端边界。

**Architecture:** `mock_services/` 使用 FastAPI 提供四个模拟域；`MockBillingClient` 通过 HTTP 调用 Mock Billing。核心业务仍以 PostgreSQL 为事实来源，Mock 服务不处理真实资金。

**Global Constraints:**

- Mock 服务不访问真实支付、CRM、监控或通知系统。
- 退款执行必须按 `idempotency_key` 幂等。
- 不保存真实凭据、银行卡号或生产数据。
