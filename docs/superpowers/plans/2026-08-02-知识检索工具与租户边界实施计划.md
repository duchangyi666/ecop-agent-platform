# 知识检索工具与租户边界实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 使用现有 `documents` 表实现租户作用域的确定性 `knowledge.search` 工具和知识检索应用服务，不引入 Milvus、RAG 或外部检索依赖。

**Architecture:** `KnowledgeRepository` 只查询当前租户 `active` 文档的标题、外部文档 ID 和来源 URI；`KnowledgeTool` 将 ORM 结果转换为安全摘要；`KnowledgeWorkflowService` 先运行主图 Guard，再在同一个 Unit of Work 内执行检索、审计和运行时追踪。

**Tech Stack:** Python 3.11.15、SQLAlchemy 2.0.36、Pydantic 2.11.4、LangGraph 1.0.9、pytest 8.3.4。
