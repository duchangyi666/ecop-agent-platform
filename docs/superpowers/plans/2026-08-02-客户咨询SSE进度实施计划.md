# 客户咨询 SSE 进度实施计划

**Goal:** 为客户咨询 API 增加 SSE 进度事件，使前端可以展示工作流开始、证据检索、生成完成和最终脱敏结果，而不是只等待整包响应。

**Architecture:** `CustomerConsultationService` 接收可选的异步 `event_sink`，在开始、证据检索和完成阶段推送事件；FastAPI 路由用 `asyncio.Queue` 接收事件并通过 `StreamingResponse` 输出 `text/event-stream`。

**Global Constraints:**

- SSE 不推送模型 Token、思维链、系统 Prompt、Key 或知识原文。
- 断流时取消当前工作流任务。
- 权限、Guard 和证据检索边界与普通客户咨询接口保持一致。
