# RAG 向量知识库实施计划

**Goal:** 为 CloudDesk 知识域补齐可审计的文档摄取、分片、Milvus 向量召回和 PostgreSQL 降级检索，使 `knowledge.search` 从标题检索升级为租户隔离的 RAG 基础链路。

**Architecture:** `POST /api/v1/knowledge/documents` 将知识正文分片写入 `knowledge_chunks`，并同步到 Milvus 向量集合；`GET /api/v1/knowledge/search` 在配置 `MILVUS_URI` 时优先向量召回，否则回退到原 PostgreSQL 检索。Embedding 默认使用确定性离线向量，BGE-M3 作为可选模型。

**Global Constraints:**

- 不导入、不复制 EduAgent 业务模块或数据库。
- 不保存原始知识正文到日志、审计或运行轨迹。
- 所有向量查询必须携带租户过滤条件。
- 未配置 Milvus 时仍可运行全部既有功能。
- 不新增未验证版本；`pymilvus==2.4.9` 使用本机已安装版本。
