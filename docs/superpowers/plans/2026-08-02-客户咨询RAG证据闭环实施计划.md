# 客户咨询 RAG 证据闭环实施计划

**Goal:** 把已完成的 Milvus/PostgreSQL 知识检索接到客户咨询模型生成前，让客服回复基于当前租户知识证据，并通过输出安全过滤判断证据依据。

**Architecture:** `CustomerConsultationService` 在调用主图前使用 `ConsultationKnowledgeRetriever` 检索证据；证据摘要进入 `AgentState.knowledge_evidence` 并注入客服模型 Prompt；`ResponseSafetyFilter` 将状态证据视为业务结论依据，未检索到证据时继续阻止无依据业务承诺。

**Global Constraints:**

- 证据检索必须使用当前租户作用域。
- 不把知识原文、完整 Prompt 或供应商响应写入日志、审计或运行轨迹。
- 未配置 Milvus 时自动回退 PostgreSQL 确定性检索。
- 自动测试默认不访问真实模型或外网。
