# 本地前端控制台实施计划

**Goal:** 提供一个由 FastAPI 静态托管的本地控制台，把 JWT Token、知识检索和 SSE 客户咨询串成可演示页面。

**Architecture:** `frontend/` 使用无构建静态 HTML/CSS/JS；FastAPI 在业务路由后挂载 `/` 静态目录。前端优先使用 Bearer Token，未获取 Token 时回退到开发 Header，方便本地演示。

**Global Constraints:**

- 不引入未验证前端依赖。
- 不暴露系统 Prompt、模型名称、Agent 名称、Chain of Thought、密钥或知识原文。
- 页面只使用已脱敏 API 响应和 SSE 事件。
- 保持企业级简洁风格，不使用霓虹渐变、漂浮光球或夸张动效。
