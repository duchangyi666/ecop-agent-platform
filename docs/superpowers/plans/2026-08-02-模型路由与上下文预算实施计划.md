# 模型路由与上下文预算实施计划

**Goal:** 为模型调用增加任务级路由、版本化 Prompt 模板和本地上下文预算，减少硬编码 Prompt 与无限拼接上下文。

**Architecture:** `ModelRouter` 按任务解析模型路由；`PromptRegistry` 保存版本化 Prompt 模板；`ContextBudget` 限制系统 Prompt 和知识证据字符量。当前作用于客服子图，路由元数据写入客户咨询审计。

**Global Constraints:**

- 不引入未验证模型或外部 Tokenizer。
- 路由和预算不改变现有 Fake/DeepSeek Gateway 的离线测试行为。
- Prompt 模板不保存密钥、思维链或供应商响应。
