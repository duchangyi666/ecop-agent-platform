# BGE-M3 稀疏召回实施计划

**Goal:** 为 Milvus 知识检索增加可选稀疏向量字段和 Dense + Sparse hybrid search。

**Architecture:** `backend/rag/sparse.py` 提供确定性稀疏 Embedder 和 FlagEmbedding BGE-M3 稀疏 Embedder；`MilvusKnowledgeVectorStore` 在 `SPARSE_VECTOR_ENABLED` 时创建含 sparse 字段的 `ecop_knowledge_chunks_v2`，使用 `AnnSearchRequest` + `RRFRanker` 执行 hybrid search。

**Global Constraints:**

- 未启用时保持现有 Dense 检索和集合行为。
- 稀疏向量不保存到 PostgreSQL 或审计。
- 真实 BGE-M3 模型加载属于可选本地验证。
