# 租户权限认证上下文实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为 FastAPI 退款和审批接口增加数据库驱动的租户身份、用户状态和权限码校验。

**Architecture:** 保留现有开发 Header 作为身份输入，通过 `UnitOfWork.identity` 在 PostgreSQL 中验证用户属于当前租户且处于 active 状态，再检查 `refund.request` 或 `refund.approve` 权限。路由只声明参数化权限依赖，不直接访问身份表；JWT/OAuth 仍作为后续可替换的身份输入适配器。

**Tech Stack:** Python 3.11.15、FastAPI 0.117.1、Pydantic 2.11.4、SQLAlchemy 2.0.36、PostgreSQL、pytest 8.3.4、pytest-asyncio 0.24.0。

## Global Constraints

- 项目完全独立于 `E:\ai\EduAgent完整代码`，只在 `E:\ai\enterprise-customer-operations-platform` 当前工作树内修改。
- Python 固定使用 `E:\anaconda3\envs\edu_agent\python.exe`，并设置 `$env:PYTHONNOUSERSITE='1'`。
- 当前身份输入只使用 `X-Tenant-Id`、`X-Actor-Id`、`X-Actor-Type` Header，不伪装成生产 JWT/OAuth。
- `refund.request` 控制退款提交和 Workflow 查询；`refund.approve` 控制审批批准/拒绝。
- API 层不直接拼接 SQL、不复制退款策略、不绕过 Unit of Work 和租户 Repository。
- 权限失败返回 403，不暴露其他租户的用户、角色或权限信息。
- 新增文档使用中文文件名，保持现有 API、退款幂等和审批状态机行为不变。

- [x] **Step 3: 实现权限依赖**

在 `backend/api/dependencies.py` 增加：

```python
def require_permission(permission_code: str):
    async def dependency(
        context: RequestContext = Depends(get_request_context),
        session_factory: async_sessionmaker[AsyncSession] = Depends(get_session_factory_dependency),
    ) -> RequestContext:
        async with UnitOfWork(session_factory, scope=context.scope) as uow:
            user = await uow.identity.get_user_in_tenant(
                scope=context.scope,
                user_id=context.scope.actor_id,
            )
            if user is None or user.status != "active":
                raise HTTPException(status_code=403, detail={"code": "tenant_identity_invalid", "message": "tenant identity is invalid"})
            if not await uow.identity.has_permission(
                scope=context.scope,
                user_id=context.scope.actor_id,
                permission_code=permission_code,
            ):
                raise HTTPException(status_code=403, detail={"code": "permission_denied", "message": "permission denied"})
        return context

    return dependency
```

路由改为：

```python
context: RequestContext = Depends(require_permission("refund.request"))
```

退款提交和 Workflow 查询使用 `refund.request`；审批路由使用 `refund.approve`。`main.py` 的 HTTPException 处理器保留 detail 中的 `code` 和 `message`，确保 403 错误合同稳定。
