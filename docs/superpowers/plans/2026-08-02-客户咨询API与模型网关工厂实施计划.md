# 客户咨询 API 与模型网关工厂实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在现有工作树上增加应用级 Model Gateway Factory、客户咨询应用服务和 FastAPI API 合同，同时保持默认 Fake Gateway 和全部离线测试。

**Architecture:** `backend/llm/factory.py` 统一根据配置创建 Fake/DeepSeek Gateway；FastAPI 应用在启动时把 Factory 创建的 Gateway 放到 `app.state`，客户咨询 API 通过依赖读取。`backend/agent/consultation_workflow.py` 调用主图并返回安全摘要，再以 UnitOfWork 写入不含原文的审计与运行时追踪。

**Tech Stack:** Python 3.11.15、FastAPI 0.117.1、Pydantic 2.11.4、LangGraph 1.0.9、SQLAlchemy 2.0.36、pytest 8.3.4。

## Global Constraints

- 继续使用 `E:\anaconda3\envs\edu_agent\python.exe` 和 `PYTHONNOUSERSITE=1`。
- 不新增依赖、不升级或降级任何已核验版本。
- 默认创建 Fake Gateway；只有 `DEEPSEEK_API_KEY` 显式存在时才创建 `DeepSeekGateway`。
- 自动测试不访问真实 DeepSeek API，不使用真实 Key。
- 不保存 Key、完整 Prompt、思维链、供应商原始响应或 Authorization Header。
- 模型只能生成结构化回复草稿，不能直接执行退款、审批、工单或数据库写入。
- 所有新增文档使用中文文件名。
- 不合并 master、不推送远程、不删除当前工作树。
