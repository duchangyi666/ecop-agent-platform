> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为已完成的 `TicketWorkflowService` 和 `KnowledgeWorkflowService` 增加 FastAPI API 合同、权限和集成测试，使工单创建与知识检索可通过 HTTP 使用。

**Architecture:** API 路由只负责请求/响应边界，调用现有应用服务；服务仍先运行主图 Guard，再在 Unit of Work 内执行业务写入或检索。自动测试使用真实数据库和 Fake Gateway，不访问外部模型。

**Tech Stack:** FastAPI 0.117.1、Pydantic 2.11.4、SQLAlchemy 2.0.36、pytest 8.3.4。
