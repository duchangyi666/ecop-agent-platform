# 长期记忆写入闭环实施计划

**Goal:** 在客户咨询结束后，将稳定的用户/企业偏好提取为可审计的长期记忆候选，并通过写入策略过滤敏感和瞬时内容。

**Architecture:** `DeterministicMemoryExtractor` 从对话消息中提取语言、时区和显式偏好；`MemoryWritePolicy` 检查置信度、长度、凭据和瞬时状态；`MemoryService` 在同一 Unit of Work 中写入 `memory_records`。

**Global Constraints:**

- 不保存原始聊天内容、最终回复、系统 Prompt 或完整业务证据。
- 记忆候选必须带租户、用户/客户、置信度、TTL、来源和哈希。
- 写入前必须通过确定性策略过滤。
- 当前是规则化记忆提取，不依赖 LLM。
