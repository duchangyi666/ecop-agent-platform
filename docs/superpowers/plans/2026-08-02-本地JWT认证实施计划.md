# 本地 JWT 认证实施计划

**Goal:** 为业务 API 增加本地签名 JWT Bearer Token 认证边界，同时保留开发 Header 降级，为后续接入正式 OAuth/SSO 提供稳定边界。

**Architecture:** `backend/auth/tokens.py` 使用 HS256 签发和校验 Token；`POST /api/v1/auth/tokens` 校验租户内活动用户后签发 Token；`get_request_context` 优先读取 `Authorization: Bearer`，未传 Token 时继续支持本地 Header。

**Global Constraints:**

- 不把密钥写入代码、日志、审计或 Token。
- Token 只包含租户、用户、角色类型、签发时间和过期时间。
- 未配置 `JWT_SECRET` 时 Token 接口返回 503，现有开发 Header 仍可使用。
- 本地 JWT 不等同于真实 OAuth、SSO 或生产身份提供商。
