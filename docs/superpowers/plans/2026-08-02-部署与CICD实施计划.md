# 部署与 CI/CD 实施计划

**Goal:** 为完整项目提供可构建的 Docker Compose 部署和 GitHub Actions CI/CD 流水线。

**Architecture:** `infra/docker/backend.Dockerfile` 构建后端 API 与 Mock 服务，`frontend.Dockerfile` + Nginx 提供前端代理；根目录 `docker-compose.yml` 编排 PostgreSQL、Redis、etcd、MinIO、Milvus、后端、Mock 服务和前端。GitHub Actions 启动依赖后执行迁移、测试和漂移检查。

**Global Constraints:**

- 不把真实密钥写入仓库；`JWT_SECRET` 从环境变量注入。
- CI 不执行真实 DeepSeek API 冒烟请求。
- Docker 镜像构建应只安装已声明依赖。
