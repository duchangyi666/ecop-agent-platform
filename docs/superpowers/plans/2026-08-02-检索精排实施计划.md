# 检索精排实施计划

**Goal:** 为 RAG 检索增加可配置精排层，默认使用确定性 RRF 排序，可选接入本地 Cross-Encoder 模型。

**Architecture:** `backend/rag/reranker.py` 提供 `KnowledgeReranker` 和 `KnowledgeDocumentReranker` 协议；`ConsultationKnowledgeRetriever` 与 `KnowledgeWorkflowService` 在混合检索后调用精排。未配置 `RERANKER_MODEL_PATH` 时使用确定性得分排序，不访问外网。

**Global Constraints:**

- 精排必须基于当前租户检索结果。
- 不把精排得分、查询原文或知识原文写入审计。
- 真实 Cross-Encoder 模型为可选本地模型，自动测试使用确定性降级。
