# 退款业务接口实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将已验收的数据库退款与审批闭环接入 FastAPI，提供可测试的退款提交、审批处理、Checkpoint 查询和健康检查接口。

**Architecture:** 新增 `backend/api` 作为 HTTP 适配层，路由只负责请求校验、开发环境租户上下文、响应映射和异常转换；退款业务继续由 `RefundWorkflowService`、`resume_refund_after_approval`、Unit of Work 和租户 Repository 执行。应用入口为 `backend/main.py`，数据库连接复用现有 `backend.database.session`。

**Tech Stack:** Python 3.11.15、FastAPI 0.117.1、Uvicorn 0.32.1、HTTPX 0.28.1、Pydantic 2.11.4、SQLAlchemy 2.0.36、PostgreSQL、LangGraph 1.0.9。

## Global Constraints

- 项目完全独立于 `E:\ai\EduAgent完整代码`，只在 `E:\ai\enterprise-customer-operations-platform` 工作树内修改。
- Python 固定使用 `E:\anaconda3\envs\edu_agent\python.exe`，并设置 `$env:PYTHONNOUSERSITE='1'`。
- 当前开发环境租户上下文只使用 `X-Tenant-Id`、`X-Actor-Id`、`X-Actor-Type` Header，不伪装成生产 JWT/OAuth。
- API 层不得直接拼接 SQL、复制退款策略、绕过 Unit of Work 或跨租户查询。
- HTTP 响应不返回完整 LangGraph State、系统 Prompt、原始模型输出、敏感工具参数或完整审计内容。
- 本阶段不接入 SSE、Redis、Worker、前端、真实认证和外部支付网关；“退款完成”只表示本地业务状态持久化。
- 新增文档使用中文文件名；Python 文件遵循生态命名约定。
