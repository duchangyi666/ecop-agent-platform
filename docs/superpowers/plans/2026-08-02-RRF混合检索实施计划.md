# RRF 混合检索实施计划

**Goal:** 在 Milvus 向量召回和 PostgreSQL 关键词检索之间加入 RRF 融合，让知识搜索和客户咨询证据检索同时兼顾语义与关键词命中。

**Architecture:** `backend/rag/hybrid.py` 对向量结果和 PostgreSQL 结果按文档 ID 去重，使用 `1 / (60 + rank)` 计算融合得分。`KnowledgeWorkflowService` 和 `ConsultationKnowledgeRetriever` 在配置 Milvus 时都使用该融合结果，未配置时保留 PostgreSQL 单一检索。

**Global Constraints:**

- 融合必须按租户作用域执行。
- 不保存检索排序细节、知识原文或查询原文到审计。
- 未配置 Milvus 时行为与既有 PostgreSQL 降级一致。
