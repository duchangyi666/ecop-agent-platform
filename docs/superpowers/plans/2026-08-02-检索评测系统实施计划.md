# 检索评测系统实施计划

**Goal:** 基于已有 Evaluation 数据表实现可运行的检索评测闭环，计算 Recall@K、Precision@K、MRR 和 NDCG@K。

**Architecture:** `EvaluationRunner` 读取当前租户数据集和用例，调用 `ConsultationKnowledgeRetriever` 执行检索，单用例指标写入 `evaluation_results`，汇总指标写入 `evaluation_runs.metrics`。API 提供 `POST /api/v1/evaluations/run` 和 `GET /api/v1/evaluations`。

**Global Constraints:**

- 评测数据按租户隔离。
- 不把原始查询、知识原文或内部排序细节写入审计。
- 未配置 Milvus 时评测使用 PostgreSQL 降级检索。
- 当前评测范围是检索链路，不冒充完整分类/决策/工具/回复评测。
