# 客户咨询 API 与模型网关工厂设计

## 1. 目标

把当前可注入的 `ModelGateway` 提升为应用运行时边界，并新增客户咨询应用服务和 HTTP API 合同。默认离线运行，只有显式配置 `DEEPSEEK_API_KEY` 时才创建 DeepSeek 网关；自动测试和本地默认启动不访问真实模型 API。

## 2. Model Gateway Factory

新增 `backend/llm/factory.py`：

```python
create_model_gateway(settings: ModelGatewaySettings | None = None) -> ModelGateway
```

行为：

- `settings.api_key is None`：返回 `FakeModelGateway`；
- `settings.api_key` 存在：返回 `DeepSeekGateway(settings)`；
- 未传入 settings：调用 `ModelGatewaySettings.from_env()` 读取运行时环境变量；
- Key 使用 `SecretStr`，不进入仓库、日志、AgentState 或 API 响应。

FastAPI 启动时执行 `create_model_gateway()` 并把结果放入 `app.state.model_gateway`。测试可通过 `create_app(model_gateway=...)` 注入离线网关，或通过依赖覆盖替换应用级网关。

## 3. 客户咨询应用服务

新增 `backend/agent/consultation_workflow.py`：

- `run_customer_consultation_graph(*, thread_id, state, model_gateway)`：调用主图并生成安全响应；
- `CustomerConsultationService(session_factory, model_gateway)`：调用图后，在当前租户 UnitOfWork 中写入 `RuntimeTrace` 和 `AuditLog`；
- 审计元数据只包含 `thread_id`、`workflow_status`、`next_action`、`response_review_code`、`model_provider`、`model_error_code`；
- 不保存用户原始消息、最终回复、Key、完整 Prompt、思维链或供应商原始响应。

状态映射：

| 场景 | status | HTTP |
| --- | --- | --- |
| 输入安全检查未通过 | `blocked` | 422 |
| 请求超出平台范围 | `out_of_scope` | 422 |
| 需要澄清 | `needs_clarification` | 200 |
| 模型正常/非客服安全回退 | `completed` | 200 |
| 模型异常、敏感输出或人工安全审核 | `human_handoff` | 202 |

## 4. API 合同

`POST /api/v1/customer-consultations`

请求 Header：

- `X-Tenant-Id`
- `X-Actor-Id`
- `X-Actor-Type`
- 可选 `X-Request-Id`

权限：`customer.consult`

请求体：

```json
{
  "thread_id": "customer-thread-001",
  "message": "客户咨询"
}
```

成功响应（示例）：

```json
{
  "request_id": "request-xxx",
  "thread_id": "customer-thread-001",
  "status": "completed",
  "next_action": "finish",
  "final_response": "您好，我可以协助处理 CloudDesk 账户、账单、产品支持和工单问题。",
  "response_review": {
    "status": "allow",
    "code": "response_allowed",
    "reason": "回复安全检查通过"
  },
  "trace_id": null,
  "audit_event_ids": [],
  "model_provider": "fake",
  "model_error_code": null
}
```

说明：

- `final_response` 只返回经过安全过滤的固定回复或结构化草稿；
- `response_review` 是安全审查结果摘要；
- `blocked` / `out_of_scope` 返回与现有 API 一致的 `ErrorResponse`；
- `human_handoff` 返回 HTTP 202，不把供应商错误原文返回客户端。

## 5. 测试与安全约束

- 全部自动测试使用 `FakeModelGateway` 或 `httpx.MockTransport`；
- API 集成测试夹具默认注入 `FakeModelGateway`；
- 不执行真实 DeepSeek API 冒烟请求；
- 不保存 `DEEPSEEK_API_KEY`、完整 Prompt、思维链或供应商原始响应；
- 模型不能直接触发退款、审批、工单或数据库写入。

## 6. 当前边界

本阶段不新增 RAG、Milvus、SSE、正式 JWT/OAuth 或第三方支付。客户咨询 API 只返回安全说明与结构化回复，不替代退款、审批和工单业务接口。
