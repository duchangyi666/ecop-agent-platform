# 工单与知识 API 合同验证记录

## 1. 验证范围

本记录对应 `enterprise-customer-operations-platform` 的工单创建和知识检索 HTTP API 合同阶段。验证内容包括：

- `POST /api/v1/tickets` 的权限、创建、Guard 拦截和响应合同；
- `GET /api/v1/knowledge/search` 的权限、文档摘要、Guard 拦截和响应合同；
- 工单服务和知识服务在 HTTP 边界仍使用租户作用域 Unit of Work；
- 既有客服、退款、审批、工单、知识、Agent 和数据库回归。

## 4. 本阶段新增行为

- 工单创建 API 需要 `ticket.create` 权限，创建成功返回 HTTP 201；
- 知识检索 API 需要 `knowledge.search` 权限，成功返回 HTTP 200；
- Guard 拦截统一映射为 HTTP 422，不创建工单、不执行检索；
- 模型和客户端请求不能直接写工单或绕过知识检索 Guard；
- 演示权限脚本支持 `ticket.create` 和 `knowledge.search`。

## 5. 当前边界

本阶段仍不接入 Milvus、RAG、SSE、正式 JWT/OAuth 或第三方支付。知识检索是 PostgreSQL 确定性检索。
