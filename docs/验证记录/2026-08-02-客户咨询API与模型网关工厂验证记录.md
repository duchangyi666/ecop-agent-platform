## 4. 本阶段新增行为

- 应用启动默认使用 `FakeModelGateway`，只有显式配置 `DEEPSEEK_API_KEY` 时才创建 `DeepSeekGateway`；
- FastAPI 通过 `app.state.model_gateway` 持有应用级 Gateway，客户咨询路由通过依赖读取；
- `POST /api/v1/customer-consultations` 需要 `customer.consult` 权限；
- 客户咨询服务调用主图，返回 `final_response`、`next_action` 和安全审查结果摘要；
- 输入安全 `block` 与 `out_of_scope` 映射为 HTTP 422，模型异常和敏感输出转人工并映射为 HTTP 202；
- 审计日志和运行时追踪只保存安全摘要，不保存用户原始消息、最终回复、Key、完整 Prompt、思维链或供应商响应；
- `scripts/seed_demo_identity.py` 已支持 `customer.consult`。

## 5. 当前边界

本阶段未接入 RAG、Milvus、SSE、正式 JWT/OAuth、第三方支付或真实模型 API 冒烟调用。客户咨询 API 只返回结构化安全回复，不替代退款、审批、工单和数据库写入接口。
