# 知识检索工具与租户边界验证记录

## 1. 验证范围

本记录对应 `enterprise-customer-operations-platform` 的知识检索工具与租户边界阶段。验证内容包括：

- `KnowledgeRepository.search_documents` 的同租户、跨租户和 active 文档过滤；
- `KnowledgeTool.search` 返回安全文档摘要；
- `KnowledgeWorkflowService` 在 Guard 通过后执行检索并写审计、运行时追踪和工具执行；
- Guard 拦截时不会执行检索；
- 既有退款、审批、客服、API、工单和租户隔离回归。

## 4. 本阶段新增行为

- 租户作用域 `KnowledgeRepository` 检索 active 文档；
- `KnowledgeTool` 只返回文档摘要，不返回正文；
- `KnowledgeWorkflowService` 在主图 Guard 和路由通过后执行检索；
- 审计和运行时记录不保存原始查询词；
- 本阶段不接入 Milvus、RAG、Embedding 或外部知识服务。

## 5. 当前边界

知识检索目前是 PostgreSQL 确定性检索，不是向量检索。尚未接入 RAG、Milvus、SSE、正式 JWT/OAuth 或第三方支付。
