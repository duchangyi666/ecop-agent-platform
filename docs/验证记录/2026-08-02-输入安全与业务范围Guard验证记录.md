## 4. 关键安全断言

- Prompt Injection、凭据/银行卡号和超长输入返回 `blocked`，不进入 Supervisor 和业务工具；
- 绕过审批、租户隔离或未授权工具返回 `human_handoff`；
- 退款接口收到非账务业务请求时返回 `out_of_scope`，不读取 Payment；
- 模糊请求返回 `needs_clarification` 和 `ask_clarification`；
- Guard 终止路径不创建 Refund、ApprovalRequest，不记录 `billing` ToolExecution；
- Guard 结果写入同一租户的 AuditLog、RuntimeTrace 和 WorkflowCheckpoint；
- 检查点会话内容使用 `[REDACTED]`，HTTP 响应不回显敏感原文；
- 正常退款、权限拒绝、幂等和审批恢复回归继续通过。

## 5. 当前明确边界

本阶段使用确定性 Python/Pydantic 规则，没有接入 LLM 安全分类器、Redis、正式 JWT/OAuth、SSE/Worker 或第三方支付网关。退款状态表示本地 PostgreSQL 业务状态已持久化，不表示第三方资金已经到账。
