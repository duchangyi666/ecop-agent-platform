## 4. 安全边界验证

- `DEEPSEEK_API_KEY` 只从运行时环境变量读取；
- 默认主图使用固定 `FakeModelGateway`，不会因导入模块而读取 Key 或创建网络连接；
- DeepSeek Gateway 的自动测试使用 `httpx.MockTransport`，只验证请求协议、重试和错误边界；
- 模型回复先经过 Pydantic 结构化校验，再经过确定性安全过滤；
- 密钥、Bearer、银行卡号、内部提示词、数据库地址和缺少证据的业务承诺会被拦截或转人工；
- 模型错误只写入固定安全错误契约，不在日志或审计记录中保存供应商原文、完整 Prompt、完整响应或 Authorization Header；客服回复草稿仅在本次图运行状态中短暂传递；
- 本项目仓库未保存用户在对话中暴露的 Key。

## 5. 当前未覆盖范围

当前阶段尚未接入 RAG、Milvus、SSE、正式 JWT/OAuth、第三方支付或真实模型 API 冒烟调用。模型不能直接执行数据库写入、退款、审批和工单工具。

如需真实模型验证，必须先撤销已暴露的旧 Key、重新生成新 Key，并仅通过本机运行时环境变量配置；该验证应作为单独的人工批准操作，不纳入自动回归。
