# 本地 JWT 认证验证记录

## 1. 验证范围

本次验证覆盖本地 JWT 认证边界：

- Token 签发、解码、错误密钥和过期 Token；
- `POST /api/v1/auth/tokens` 的用户校验；
- Bearer Token 访问业务 API；
- 无效和过期 Token 返回 HTTP 401；
- 开发 Header 降级不受影响。
