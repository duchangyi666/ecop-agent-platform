# 工单工具与租户事务验证记录

## 1. 验证范围

本记录对应 `enterprise-customer-operations-platform` 的工单工具与租户事务阶段。验证内容包括：

- `SupportRepository.create_ticket` 扩展 `description_summary`、`category`、`initial_message`；
- `SupportRepository.update_ticket_status` 显式状态机、`TicketEvent` 和 `TicketMessage`；
- `TicketTool.create` / `TicketTool.update`；
- `TicketWorkflowService` 在 Guard 通过后创建租户工单，并写入审计、运行时追踪和工具执行；
- Guard 拦截时不会创建工单；
- 既有退款、审批、租户隔离、Agent、客服和 API 回归。

## 4. 本阶段新增行为

- 工单创建支持描述摘要和初始消息，并记录 `ticket_created` 事件；
- 工单状态更新只能通过 `transition_ticket` 状态机，并记录 `status_changed` 事件和内部消息；
- `TicketTool` 只通过租户作用域 `SupportRepository` 操作工单；
- `TicketWorkflowService` 在主图 Guard 和路由通过后，于同一 Unit of Work 内执行工单写入、审计、运行时追踪和工具执行；
- Guard 拦截、跨域或跨租户请求不会创建工单；
- 审计和运行时记录不保存完整工单正文、用户原始消息、完整 Prompt、思维链、供应商响应或 Key。

## 5. 当前边界

当前已完成工单创建和状态转换工具及租户事务服务。尚未接入工单查询 API、SSE、正式 JWT/OAuth、知识库 RAG 或第三方支付。模型和客服结构化回复不能直接触发工单写入。
