# RAG 向量知识库验证记录

## 1. 验证范围

本次验证覆盖 CloudDesk 知识域新增的 RAG 基础链路：

- `knowledge_chunks` 迁移和数据库结构验收；
- 知识摄取 API 的权限、分片、审计和向量同步；
- Milvus 租户过滤向量召回；
- 未配置 Milvus 时的 PostgreSQL 降级检索；
- 既有退款、工单、Agent、API 和数据库回归。

## 2. 实际验证环境

继续使用项目指定解释器和 `PYTHONNOUSERSITE=1`：

```text

Milvus http://localhost:19531
PostgreSQL localhost:54329
Alembic head 006
```

## 5. 当前边界

本阶段是 RAG 基础层，不是完整混合检索。BGE-M3 默认不加载，需通过 `BGE_M3_MODEL_PATH` 显式指定本地模型；尚未接入 Reranker、正式 JWT/OAuth 或第三方支付；SSE 已在客户咨询 API 提供进度事件。
